# Project Vision

The ultimate goal of this project is to create a playful, benign Twitter bot designed to engage with Elon Musk's tweets using clean, space, engineering, and Mars-themed humor. The bot is intended to be lighthearted and tactful, avoiding controversy while adhering to platform API limitations and automation rules.

## Core Concepts
*   **Tactful Humor:** Utilizing clean, family-friendly jokes and fascinating astrophysics facts.
*   **Automation Safety:** Operating safely within X API rate limits and preventing spam through delayed responses (4-6 hours) and dynamic sentiment analysis.
*   **Maintainability & Observability:** Providing a comprehensive single-page Command Center web dashboard and desktop system tray companion for monitoring, diagnostics, and testing.

## User-Satisfaction Design
*   **Unified Single-Page Dashboard:** Consolidated view of metrics, sentiment sandboxes, runtime configuration, and streaming logs with detailed tooltip guidance.
*   **Dry-run functionality:** Allowing developers and operators to simulate the bot logic without consuming API credits.
*   **Detailed Logging & Diagnostics:** Providing clear, timestamped in-memory log streaming and analytics summaries upon shutdown.
